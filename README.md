# 孤岛文明沙盘

**在线：https://dingdjfjs-star.github.io/island-civ-sandbox/ · 仓库：https://github.com/dingdjfjs-star/island-civ-sandbox**（api.github.com 通道部署，GitHub Actions/legacy Pages 均无需干预）

网页"孤岛文明沙盘"模拟 Demo：一块种子生成的孤岛，四支部落从采集萌芽开始扩张、相遇、
冲突或合并、迁徙、分裂、兴盛或消亡——全程规则驱动，同种子同设定，同历史，零依赖零构建。

- **单文件 `index.html`**：原生 JS + Canvas，无 CDN、无模块、无 fetch，file:// 双击直开可玩
- **有性格的部落**：好战/温和/扩张三族性开局随机抽签（分家承继家风）；世界设定面板可调
  开局部落数、好战度（开战频率倍率）与自愿合并开关
- **看得到的历史**：领地罩色与描边、随人口分级的据点圆标与部落名、灭亡部落淡出、
  编年史按事件着色自动滚动、悬停任意瓦片查地类/资源/肥力/归属
- **确定性的世界**：随机数全部走内部种子化 PRNG，同一 seed 两次运行事件序列逐位一致

## 玩法步骤

1. **打开**：双击 `index.html`（或双击 `启动.bat`），左侧是孤岛地图，右侧是控制区与编年史
2. **开始**：点"开始"按钮（再点变"暂停"）；速度档 ×1/×2/×5/×20/×60 = 每秒推进的年数，
   运行中切换即时生效
3. **换种子**：右侧种子框输入任意整数后回车或点"重置"——新世界；再点"重置"用当前种子
   重开同一历史（同种子同设定，同历史）
4. **给他们设定**（设定面板改动在点"重置"后生效）：
   - **部落**：开局部落数 2~8
   - **好战度**：开战频率全局倍率——0% 永不开战（纯和平演变），100% 标准，300% 战火连天
   - **允许自愿合并**：关掉后太平再久也不会有"自愿并入"，分合只剩打出来的吞并
   - 每个部落开局按种子随机抽**族性**（好战/温和/扩张），花名册直接标注；
     分裂出的新部落承继母族性格（家风不改）
5. **看世界**：
   - 地图：七类地形着色；部落领地罩色 + 异色描边；据点圆标随人口变大并缓动，
     上方标注部落名；灭亡部落约 2.2 秒淡出
   - 悬停任意瓦片：tooltip 显示坐标、地类、食物/木材/石料存量、肥力、所属部落与人口
   - 控制区：年份/部落数/总人口/领地格数实时显示；地类图例；部落花名册
     （标注族性；已灭部落置灰并注记除名年份，悬停看详情）
   - 编年史：最新在底部自动滚动，按事件类型着色（建部绿/相遇淡蓝/冲突红/休战青/
     合并粉/分裂橙/饥荒黄/迁徙蓝/灭亡灰），上限 400 条
6. **节奏参考**：×60 档约 33 秒走完 2000 年；开局几十年是安静的采集扩张期，
   第 40~100 年间开始相遇，之后冲突、迁徙、分合轮番上演，终局一般剩 3~10 家共存

## 模拟规则详解

模拟核心按"年"推进（`world.tick()`），每年对每个部落依次做：采集 → 吃饭/增长/饥荒 →
迁徙 → 扩张 → 消亡判定；全部部落结算完后做部落互动（相遇/冲突/休战/吞并/自愿合并）、
分裂，最后全图资源再生。

### 地形与资源

- 高度场 = 多层 Perlin 噪声（fbm 5 层）× 径向衰减（边缘沉海）+ 噪声扰动海岸线，
  对比度拉伸拉开峰谷；**海平面按目标陆地占比（`landTarget`）取高度分位数自适应标定**，
  任何种子下孤岛规模都稳定
- 七类地型：深海/浅海/沙滩/平原/森林/山地/雪峰；湿度场（第二组独立噪声）决定平原带
  何处长林、林子多密
- 每格陆地有三资源存量（食物/木材/石料，0~1，按地型基准 × 随机抖动）与**肥力**（0~1）：
  资源按"缺口 × regrowRate × 肥力"逐年向初始丰度再生；过度采集扣肥力、撂荒缓慢回复

### 部落生成

开局 4 支部落（`initialTribes`）：平原 > 森林 > 沙滩分层优先评分选址，保持最小间距；
人口 8~15，开局存粮 = 人口 × 口粮 × 2 年，以据点为心圈半径 2 的领地。部落名 =
颜色字 + 图腾 + 部落/氏族（如"赤鹿部落"），开局不重名；配色从高区分度调色板轮转。

### 采集与人口

- **两遍制采集**：年目标 = 口粮 × `gatherMargin`（1.25）。第一遍"轻采"——领地内
  先近后远，每格至多采走可采出量的 45%（`overFrac`），不伤地力；仍不够再"深挖"存量，
  超限的格子记过度采集（年末扣肥力 0.05）。木材石料随领地附带轻采
- **吃饭**：粮不够先吃库存；库存见底按缺口比例减员（`famineDeathFrac`）并发饥荒事件
  （同部落 6 年内不重复发）
- **增长**：本年有盈余且人口未达领地承载力 K（领地可持续产出 ÷ 口粮，随肥力缩水）时
  逻辑斯蒂增长（`popGrowR`）。**承载力封顶 + 超额采集伤地力**是全沙盘的基本矛盾：
  人口顶到 K 后每年必有 25% 缺口靠"深挖"补——故土肥力被磨穿只是时间问题

### 迁徙

据点周边（半径 4 内领地）平均肥力 < `fertCollapse`（0.35）→ 举族在半径 14 内找肥力达标
的无主可居地整体搬迁（`migrated` 事件）；无地可去则人口每年额外衰减 6% 等死。
迁徙在世界上呈**浪潮**状：一片地被磨穿 → 一串部落接连搬家 → 撂荒地几十年后复原。

### 相遇之后：冲突、休战、吞并、自愿合并

领地相邻即"接壤"（`contact` 事件；分离超过 4 年才解除，防边界抖动刷屏）。接壤期间
每年判定开战：概率 = `conflictBase` × 拥挤度 × 实力差加成 × **双边族性均值** × **好战度**
（世界设定倍率）。开战双方掉人口，败方（人口少的一方）加倍放血，之后三选一：

- 人口见底 → **灭亡**（`extinct`）
- 人口 ≤ 胜方 15% → 据点陷落，举族**被吞并**（`merge`，丁口领地尽归胜者）
- 一战折损过 80% → 35% 概率被迫**举族迁走**（`migrated`）

窗口内连续 3 场冲突 → 鸣金**休战** 10 年；接壤 30 年无冲突且一方人口明显偏小
（≤ 另一方 25% × 小族"认亲门槛"：温和族 ×1.6 更容易并、好战族 ×0.5 更不肯低头）
→ 小方**自愿并入**（`merge`）。

### 部落性格（好战 / 温和 / 扩张）

建部时按种子抽签（占比 `hawkFrac`/`doveFrac`，其余扩张；同 seed 同布局），花名册与
建部事件都会标注族性：

- **好战**（约 30%）：开战欲望 ×2.4——边境摩擦多由他们挑起；自愿并入门槛打折
  （×0.5），小族硬扛到最后一刻
- **温和**（约 30%）：开战欲望 ×0.35——太平使者；弱小时更容易认亲合族（门槛 ×1.6）
- **扩张**（其余）：圈地配额 ×2——领地涨得快、容易与四邻接壤；开战欲望略高（×1.2）
- 关闭 `personalityOn` → 人人中性，行为与无性格版一致

分裂出的新部落**承继母族性格**；吞并后胜者性格不变。"会不会一直打架/最终统一"：
好战度拉满时冲突显著增多、吞并更快，但一统全岛必触发"裂土分家"再裂开——
长期是战争-合并-分裂的循环，不会死局式统一。

### 分裂与裂土分家

人口超过 240（`splitThreshold`）→ 分出新部落，带走 45% 人口与库存，继承母部落变体色
（RGB 通道轮转）。优先找无主可居地落址；**岛上已圈满时改为"裂土分家"**——在母部落
领地内挑一块沃土做分支据点，把周边领地划过去（否则全岛一统后再无空地，沙盘会陷入
千年死局）。统一与分裂交替，是终局"几家共存"的来源。

### 灭亡

人口 < 1 即除名（饥荒耗尽、冲突灭族都可能）。部落 id 只增不复用。注意展示上限：
编年史与事件历史都只保留最近 400 条（超出即丢弃最旧，约覆盖最近三百余年），花名册
只保留最近 24 个已消失部落——千年级演化中更早消失的名字不会一直挂在界面上。

### 调参指南（往哪拧动哪个"好玩"旋钮）

- **想更动荡**：`conflictBase` ↑（更多开战）、`gatherMargin` ↑（口粮压力更大 → 过度采集
  与饥荒更多 → 迁徙更频繁）、`splitThreshold` ↓（更容易分家）
- **想更太平**：`conflictBase` ↓、`peaceMergeGap` ↓（更快走向自愿合并）、`gatherMargin` ↓
- **人口规模感**：`popPerTile`（领地 ambitions）、`tileFoodYield`（全岛承载力）、
  `stockCap*`（囤积上限）、`popGrowR`（增长快慢）
- **扩张速度**：`claimPerYearMax` / `claimCatchFrac` / `popPerTile`
- **迁徙浪潮频率**：`fertCollapse` ↑（更容易觉得"故土完蛋了"）、`fertHit` / `fertHeal` /
  `regrowRate`（地力磨穿与恢复的时间尺度）
- **地貌**：`landTarget`（岛大岛小）、`fbmBaseFreq`（破碎/完整）、`warpAmp`（海岸锯齿）、
  `noiseContrast`（山地板块感）
- **纪律**：只准新增键；改动后必跑 `node test\test.js`（89 万+断言含平衡门槛回归，
  10 个平衡种子见下），再用 `node test\probe.js --ticks 2000` 与 `node test\trace.js`
  观察轨迹

## 复现与测试

### 同种子复现

同一 seed + 同一设定两次运行，事件序列**逐位一致**——随机数全部来自内部 mulberry32
种子流（地形生成消耗固定次数，年度结算按部落 id 升序、领地按固定顺序扫描），不接 AI、
不联网、无外部随机源；开局部落数、好战度、自愿合并开关都是世界的一部分，改设定即改历史。
浏览器里：输入同一种子、拨好同一套设定，点"重置"即重演同一部历史。

### 测试与探针

```
node test\test.js                        # 全量 headless 断言套件（89 万+断言，约 30 秒）——交付门槛
node test\probe.js                       # 三种子（20261105/42/99）× 200 年快检
node test\probe.js --ticks 2000          # 三种子 × 2000 年 × 各两遍：节奏自检（六类事件齐现）
node test\probe.js --seeds 1,7 --ticks 2000   # 指定多种子
node test\trace.js --seed 20261105 --ticks 2000 --every 100   # 轨迹调试：逐年状态
node test\trace.js --seed 42 --ticks 300 --every -1           # 轨迹调试：逐事件流
node test\ui-smoke.js                    # UI 静态冒烟（36 项）：纪律/元素/配色接线
node test\ui-loop.js                     # UI 逻辑探针（26 项）：桩 DOM 跑真 UI——滴答/暂停/重置/tooltip
```

`test/test.js`（阶段五新增）覆盖八大组：SIM-CORE 可抽取且剥离注释后无任何 DOM/BOM/网络
引用；CONFIG 键无 undefined 且契约键在位；地形健全（landRatio、资源范围、海格恒零）；
同种子两次运行 2000 年事件流逐位一致 + 终局世界哈希一致；10 种子 × 2000 年逐年不变量

## 技术实现要点

- **单文件双脚本段**：`/* ===== SIM-CORE-BEGIN ===== */` 与 `/* ===== SIM-CORE-END ===== */`
  之间是纯逻辑模拟核心（禁一切 DOM API，随机只走内部种子化 PRNG）；渲染与 UI 全在
  END 之后。`test/` 下的探针靠这两个标记把核心抽出来在 node 里直接跑
- **PRNG 与噪声**：mulberry32 种子流；经典二维 Perlin 三组独立置换表（地形/海岸扰动/湿度）；
  fbm 多层叠加；海平面按 `landTarget` 分位数自适应 + 钳制
- **性能关键路径（阶段五重写）**：每年每部落一次 O(领地) 预扫——计数排序按"到据点
  切比雪夫距离"生成采集顺序（先近后远，同距按主张序，零分配复用缓冲），顺带聚合
  肥力检查量、可持续产出与木石轻采；扩张改为"一年一遍候选全扫 + 逐块增量补扫"，
  与旧的全扫语义逐位等价。取代旧实现的逐年 `slice+sort`（曾占整年结算近四成）与
  多遍全领地遍历，2000 年耗时降为原来的约 1/4
- **主循环**：rAF + 累加器按速度档"年/秒"滴答，单帧封顶 120 滴答、超限丢欠账；
  200ms `setInterval` 兜底心跳与 rAF 共用同一 `pump()`（嵌入式/被遮挡浏览器 rAF
  停摆时仍按节拍推进，不重复滴答）
- **file:// 纪律**：无模块、无 fetch/XHR、无外链；`test/ui-smoke.js` 静态断言把关
