## 接手时的状态

## 平衡调试记录（按轮）

判定标准（任务书）：开局沉寂、随后扩张、数十年到百年内开始相遇冲突、间或有迁徙浪潮、
终局几家共存；不允许 2000 年内全体灭绝、不允许世界冻结。度量工具为临时脚本
（画像/病理扫描/浪潮形态/阈值校准，未入库），结论全部落在本报告与 test/test.js 门槛里。

### 第 2 轮：性能不达标 → 核心去排序化重写（唯一实质性改动）

**问题**：单种子 2000 年实测 5695~8349 ms，远超任务书 3 秒门槛。V8 profile
（node --prof，1361 ticks 采样）显示：`harvestTribe` 逐年 `slice().sort()` 的比较器与
TimSort 占 **37%**（比较器单项 24.8%），`harvestTribe` 本体 13%，另有 `sustainTribe`
6.5%、`expandTribe` 4.4%、`tryMigrate` 3.7% 等多遍 O(领地) 扫描。

**修复**（全部在 SIM-CORE 内，算法级，规则语义不变；CONFIG 零改动）：

1. **领地预扫 `prepassTribe`**：每部落每年一次 O(领地) 计数排序，按"到据点切比雪夫
   距离"生成采集顺序（先近后远；同距按主张序——旧实现为同距按索引序，属唯一行为漂移，
   见下），零分配（模块级复用 `ORD/DIS/CNT/PRE` 缓冲）；一次顺带聚合肥力检查量
   （迁徙触发）、可持续产出（承载力）并把木石附带轻采并入（逐瓦片独立、与序无关）。
   取代旧实现的逐年排序 + 三遍独立全领地遍历。
2. **扩张增量候选表**：每年只对领地做一遍候选全扫，此后每主张一块只补扫新瓦片邻格；
   新瓦片总在领地主张序末尾，选取序与旧"每轮全扫"逐位一致（评分只依赖候选格自身，
   同分先见先得）。
3. **互动结算去字符串化**：部落对排序改为预解析数值对排序，去掉逐年 `split('|')` 分配。
4. 热循环 `CONFIG.*` 成员提升为局部变量（regrowTiles 等）。

**结果**：2000 年耗时 20261105/42/99 三种子 5695/6405-52/8349-56 ms → **1423/1567/2010 ms**
（约 4 倍），全部低于 3 秒门槛；test.js 计时 1862 ms。

**行为漂移说明（如实记录）**：预扫后采集"同距"遍历序由索引序改为主张序（距离序不变），
这会移动"最后一格谁挨深挖"的边际归属，事件流与阶段三/四的记录数字不再逐项相同；
确定性本身不受影响（同种子两遍仍逐位一致），全部平衡指标复测达标（第 3 轮）。
probe 的节奏自检（六类事件齐现）复测通过。

### 第 3 轮：重写后复测 + 50 种子病理扫描

- 10 种子平衡画像复测：全部指标维持达标（终局 3~10 部落、498~1249 人；峰值/开局人口
  34~64 倍；首冲突 y55~104；迁徙 50 年窗峰值 22~96；第 100 年后最大事件间隔 7~28 年）。
- 病理扫描（2000 年/种子）：种子 1~30 与 987654~987673 共 50 个——**零全体灭绝、
  零冻结（最大间隔 ≤ 28 年）、零 NaN、全部种子出现冲突（首冲突 y26~116）**。
- 结论：**不需要动任何 CONFIG 平衡旋钮**；本阶段 CONFIG 与阶段四交付版逐键一致
  （零新增零改名零删除），平衡工作以"度量 + 算法修复 + 门槛固化"完成。

## test/test.js（阶段五新增，交付门槛）

风格：大量小断言、失败全部列出、全绿退出码 0。八大组覆盖（详见文件头注释）：
SIM-CORE 抽取与无 DOM 纪律（剥离注释/字符串后按词边界扫 33 个违禁词）、CONFIG 契约
（键无 undefined、全有限数字、21 个契约键在位）、地形健全、确定性（事件流 JSON 逐位 +
终局世界哈希）、运行不变量（10 种子 × 2000 年逐年：NaN/负值/越限/归属互洽/id 升序/
年份/事件形状/人口硬上界）、平衡门槛（13 条，阈值均按实测留 ≥2 倍余量）、性能
（单种子 2000 年 < 3 s，取两次计时较小值防抖动）、建世契约杂项。

## 五阶段构建小结

- **阶段一（地形）**：接手时为空白项目；最终交付 mulberry32 + 三组独立置换表 Perlin +
  fbm 的孤岛生成——径向衰减保证边缘沉海、海平面按 landTarget 分位数自适应（任何种子
  陆地占比稳定 0.30）、对比度拉伸保证山地雪峰、湿度场控林；七类地型 + 三资源 + 肥力。
- **阶段二（部落）**：在静态孤岛上加生命：评分选址建 4 部、两遍制采集（轻采/深挖）、
  逻辑斯蒂增长与饥荒、人口驱动扩张、肥力-撂荒-迁徙循环、消亡除名。"承载力封顶 +
  gatherMargin>1 ⇒ 饱和部落年年深挖"是后来一切迁徙浪潮的发动机。
- **阶段三（演化）**：部落间秩序——接壤相遇、概率开战、败方三出路（灭/吞并/迁走）、
  连战休战、长期和平自愿合并、人丁过盛分裂；开发中抓出并修复"全岛一统后 split 无地
  可去陷入千年死局"的结构性问题（补裂土分家）。
- **阶段四（界面）**：SIM-CORE 零改动装配渲染/UI：rAF+累加器主循环（×1~×60）、领地
  罩色描边、人口分级据点与名注记、灭亡淡出、编年史着色滚动、名册置灰、悬停 tooltip；
  并修复嵌入式浏览器 rAF 停摆问题（200ms 兜底心跳共用 pump）。本阶段接手时全部在位。
- **阶段五（平衡/测试/文档，本阶段）**：接手时无平衡度量、无 headless 套件、性能未达
  标。改动：① 新增 test/test.js（89 万+断言）；② 系统度量平衡——基线即达标，规则系数
  一字未动，CONFIG 与阶段四逐键一致；③ 唯一实质修改是 SIM-CORE 性能重写（预扫计数
  排序 + 增量扩张候选 + 去字符串化），2000 年耗时降为 1/4，行为漂移仅"同距采集序改
  主张序"一处，已如实记录；④ README 全面重写（玩法/规则/参数表/调参指南/复现）、
  新增 启动.bat、侧栏副标题改为中性文案。遗留：部落名注记无碰撞避让（阶段四已知）；
  节流宿主里画布随心跳低帧率重绘（阶段四已知，浏览器冒烟中实测被遮挡标签页约
  15 年/秒，前台全速）；famine 事件量较大（415~850 次/2000 年，黄字密度高）属观感项
  未调；平衡种子集外若未来扩种子池，个别种子首相遇可能早至 y8（2024），属容差内方差。

## 遗留与建议

- `test/test.js` 的平衡阈值按当前规则校准（各留 ≥2 倍余量）；若后续阶段改规则系数，
  以 test.js 为回归门槛重校准即可。
- UI 侧遗留项沿用阶段四报告：注记避让、devicePixelRatio 分辨率、淡出中间帧未逐帧目验。
- famine 事件若嫌刷屏，可调 `famineGap` ↑ 或 `famineDeathFrac` ↓（见 README 调参指南）。
