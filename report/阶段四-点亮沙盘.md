# 阶段四质检报告：点亮沙盘

日期：2026-11-06 · 范围：渲染与 UI 装配（SIM-CORE 零改动）

## 本阶段做了什么

全部改动位于 `index.html` 的 SIM-CORE-END 标记之后的渲染/UI 薄壳与侧栏 HTML/CSS，
模拟核心一个字未动（探针事件流计数与阶段三逐项一致可证）。

1. **主渲染**：地形离屏缓存保留（地形色只依赖地型与林密度，随世界重建重画一次）；
   每帧叠加——领地按部落色半透明罩色（alpha 0.38）；一遍扫描 claims 数组，在相邻异色
   （含无主/海侧）瓦片之间画 1px 描边线（描边色随瓦片归属）；据点圆标半径随人口开方
   增长并封顶（`markerR`，2.6~9px），逐帧向目标半径缓动 18%（画面随年份平滑过渡）；
   部落名描边注记最后统一绘制（不被标记压住）；灭亡部落（冲突灭/被并）在 tick 前快照
   领地，死亡后以"幽灵"实体淡出约 2.2 秒（真实时间），同屏上限 24 个。
2. **主循环**：`pump()` 为唯一循环本体——rAF 每帧调用，把真实时间按速度档（×1/×2/×5/
   ×20/×60 = 年/秒）经累加器折算成滴答；单帧滴答封顶 120、超限丢欠账（防死亡螺旋）；
   dt 钳制 250ms（防后台切回大步进）；暂停时不推进但保持渲染。另设 200ms `setInterval`
   兜底心跳调用同一 `pump()`（见"开发发现"）。
3. **控制区**：开始/暂停同按钮切换文案；速度档五档下拉；重置用种子框当前种子重开
   （保留播放状态）；种子输入 + "同种子同历史"提示；年份/部落/人口/领地实时显示；
   花名册色点+名字+人口，已灭部落置灰并注记除名年份（保留最近 24 条，title 悬停看详情）。
4. **日志面板**：编年史改为最新在底部并自动滚动（`scrollTop = scrollHeight`）；按 9 类
   事件着色（founded 草绿/contact 淡蓝/conflict 砖红/peace 青玉/merge 蔷薇/split 橙/
   famine 麦黄/migrated 天蓝/extinct 石灰）；上限 400 条（超出丢最旧）；格式"第 N 年 · 内容"。
5. **悬停 tooltip**：mousemove 按画布 CSS 缩放比折算回瓦片坐标，显示坐标/地类/三资源/
   肥力%/所属部落（人口，据点标注"· 据点"），靠近边缘自动翻转，mouseleave 隐藏。
6. **file:// 纪律**：无模块、无 fetch/XHR、无外链（ui-smoke 断言把关）。

## 开发发现与修复（1 处）

**嵌入式/被遮挡环境中 rAF 停摆，纯 rAF 沙盘会"点了开始没反应"。**
浏览器冒烟时实测：ZCode 内置浏览器对被遮挡标签页完全不泵帧（`requestAnimationFrame`
1 秒 0 帧，`visibility` 能力上报 true 也无效），点击"开始"后按钮切换正常但年份不动。
这是浏览器对后台页的标准节流行为，但会让沙盘在这类宿主（含用户在内置浏览器里的预览）
里表现为冻结。修复：保留 rAF 主循环不动，增加 200ms `setInterval` 兜底心跳调用同一个
`pump()`——两路共用同一累加器（rAF 活跃时心跳空转，停摆时心跳按 dt 钳制继续推进），
不会重复滴答，×60 档在心跳单独驱动下也保持正确年/秒（每次心跳 dt≈200ms → 约 12 滴答）。
真实可见的浏览器里行为与纯 rAF 版完全一致。

## 遗留与建议（给后续阶段）

- 速度档/心跳/淡出时长等 UI 侧参数按纪律放进了 END 之后的 UI 常量区（GHOST_MS、
  LOG_MAX、ROSTER_DEAD_MAX 等），未塞进 CONFIG——如后续阶段想让用户可调，再以"只增"
  方式入 CONFIG。
- 部落名注记在部落密集处可能互相压盖，未做碰撞避让；若后续做"点选部落看详情"，可顺带
  做选中高亮与避让。
- canvas 使用 `image-rendering: pixelated`，窗口小于画布时整页缩放、注记文字略糊；
  若后续要大屏演示可考虑按 devicePixelRatio 提升内部分辨率。
